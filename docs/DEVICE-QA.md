# 실기기 검증 기록

현재 결과: **실제 휴대폰을 연결하지 않았으므로 미실시**. Playwright의 모바일 뷰포트 검사는 실기기 검증과 구분한다.

운영 HTTPS 주소: 미정 / 기종·OS·브라우저: 미확인 / 확인일: 미정

| 항목 | 확인 방법 | 현재 결과 |
|---|---|---|
| 일반 모바일 웹 | 링크 열기, 로그인, 하단 메뉴, 뒤로가기 | 자동화 통과 / 실기기 미실시 |
| 이메일 인증 | 실제 받은 메일 링크를 같은/다른 기기에서 열어 인증 후 재로그인 | 모의 발송 자동화 통과 / 외부 메일 미실시 |
| 비밀번호 복구 | 메일 링크 → 변경 → 이전 비밀번호/기존 기기 로그인 해제 | 자동화 통과 / 외부 메일 미실시 |
| 사진 | 카메라 촬영·앨범 선택·사진 회전·업로드 후 확인 | 테스트 파일 자동화 / 실제 카메라 미실시 |
| 위치 허용/거부 | 내 계정의 기기 확인, 제보의 현재 위치 버튼 | 모의 위치·거부 자동화 통과 / 실기기 미실시 |
| 나침반 | 북·동·남·서 현장 비교, 기기 회전, 권한 거부 후 수동 방향 | 실기기 미실시 |
| 키보드·안전 영역 | 작은 기기에서 마지막 입력과 제출 버튼, 가로 회전 | 320/360/430px 가로 넘침·입력 글씨 검사 통과 / 실기기 미실시 |
| 홈 화면 추가 | 아이콘·이름·단독 창·재실행 로그인 유지 | manifest 자동화 통과 / 설치 미실시 |
| 푸시 | 설치된 웹앱에서 알림 켜기 → 기기 확인 → 테스트 알림, 앱 닫고 재확인 | 모의 발송 자동화 / 실제 도착 미실시 |
| 오프라인 | 데이터/Wi-Fi 끄고 재접속 후 복구 | 자동화 통과 / 실기기 미실시 |
| 공유·QR | 공유 시트와 전단 QR를 다른 휴대폰으로 열기 | 파일 다운로드 자동화 / QR 카메라 미실시 |

민감한 계정 정보와 실제 위치 좌표는 이 문서에 기록하지 않는다. 실패 항목은 기종·OS와 재현 순서만 기록한다.

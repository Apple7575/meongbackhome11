# 멍백홈

전국 실종 강아지 신고·목격 제보·재회를 연결하는 모바일 웹입니다. 사용자가 제공한 흰 강아지를 대표 마스코트로 사용하며 코랄색 인식표와 크림·세이지 색상을 적용했습니다.

## 실행

현재 운영 배포 대상은 **Vercel Hobby + Supabase Free**입니다. [무료 배포 안내](docs/VERCEL-SUPABASE.md)를 참고하세요. 아래 SQLite 실행은 로컬 개발용이며, 클라우드는 별도의 PostgreSQL API와 비공개 사진 저장소를 사용합니다.

Node.js 24 이상을 사용하세요.

```sh
npm ci
npm run dev
```

웹은 `http://localhost:5173`, API는 `http://localhost:3001`에서 함께 실행됩니다. Vite의 `/api` 프록시로 같은 출처의 세션 쿠키를 사용합니다. SQLite 파일과 VAPID 키는 `data/meongback.sqlite`에 저장됩니다.

```sh
npm run build
npm start
```

빌드 후 `npm start`는 웹과 API를 모두 3001 포트에서 제공합니다. Dockerfile, Compose, Caddy와 [기존 운영 안내](docs/OPERATIONS.md)는 자체 서버 배포의 대안입니다. **Vercel에 웹·API 코드는 배포했지만, Supabase 계정 연결과 운영 환경 변수 설정 전이라 아직 실사용 가능한 상태는 아닙니다.** 현재 상태와 연결 절차는 [무료 배포 안내](docs/VERCEL-SUPABASE.md)에 기록합니다.

## 이번 개선

1. **대표 캐릭터**: 제공된 강아지를 기준으로 기본·수색·새 소식·재회 이미지 제작. 실제 PNG 알파 채널 검사와 WebP 최적화.
2. **상황별 홈**: 처음 방문하면 서비스 소개, 실종 신고를 등록한 보호자에게는 내 아이의 최근 목격·제보 수·알림과 지도 진입 제공.
3. **목격 지도**: 카드 좌우 스와이프, 지도 마커 선택 동기화, 시간순 재생·일시정지, 확인 상태 구분, 모바일에서 확장되는 제보 패널.
4. **단계별 입력**: 신고·제보·프로필 3단계, 단계별 검증, 사진·위치·방향을 포함하는 7일 초안, 등록 전 확인, 등록 후 공유·QR 전단 안내.
5. **세부 경험**: 주요 정보 글씨와 대비 개선, 사진 처리 중 표시, 서버 저장 상태, 실패 시 입력 유지와 재시도, 연결 재시도, 모션 감소, 키보드 접근성.
6. **실제 연결**: 서버 저장, 이메일/비밀번호 계정과 세션, 다른 브라우저의 신고 조회·제보, 당사자 대화, SSE 실시간 알림, 관심 지역/저장한 신고/제보자 재회 알림, Web Push 구독·발송 큐·재시도.

기존 검색·지역/외형 필터, 발견 제보 추천, 프로필 재사용, 수색 상황, 신고 저장, QR/SNS 전단, 재회 후기, 운영자 신고 관리도 유지합니다.

## 데이터와 권한

- 실종 신고 등록에는 계정이 필요합니다. 발견 제보와 조회는 회원가입 없이 시작할 수 있습니다.
- 로그인 전 프로필·제보는 HTTP-only 세션으로 관리합니다. 같은 세션에서 회원가입하면 소유권이 유지됩니다. 쿠키를 삭제하면 비회원 기록을 관리할 수 없으므로 다른 기기에서 관리하려면 계정을 연결하세요.
- 비밀번호는 무작위 salt와 scrypt로 저장합니다. 세션 토큰은 DB에 해시로 저장합니다.
- 보호자만 실종 신고·제보 확인 상태·수색 상황을 변경합니다. 대화는 해당 보호자와 제보자에게만 전달됩니다.
- ‘보호 중’·‘기관 인계’ 제보는 당사자가 아닌 사람에게 정확한 좌표, 상세 위치, 본문, 사진을 숨깁니다.
- 변경 버전으로 동시 수정 충돌을 감지합니다. 저장 트랜잭션이 실패하면 DB 변경과 알림 생성을 함께 취소합니다.
- 서버 알림은 사용자별로 저장합니다. SSE 신호에는 개인정보가 없으며 클라이언트가 자기 권한으로 새 상태를 조회합니다.
- 작성 중인 초안은 브라우저에만 저장되고 등록 완료 후 삭제됩니다. 이전 로컬 프로토타입 기록은 자동 업로드하지 않습니다.
- 예시 신고는 `demo`로 명시하고 수정하지 못하게 합니다. 운영 환경은 `SEED_EXAMPLES=false`로 시작합니다.

## 지도 규칙

목격 **시각**을 기준으로 점선을 연결합니다. 점선에는 이동 방향을 부여하지 않으며 실제 경로라는 의미가 아닙니다. 각 지점의 코랄색 화살표는 그때 제보된 방향만 표시합니다. `heading: 0`은 북쪽이고 `null`은 모름입니다. ‘머물러 있었어요’는 별도 상태이며 ‘다른 강아지’ 제보는 해당 타임라인에서 제외합니다. 나침반 미지원·거부·시간 초과 시에도 수동 방향 지정이 가능합니다.

## 검증

```sh
npm test
npm run build
npm run test:browser
node scripts/capture.mjs
```

브라우저 테스트는 빌드된 화면을 별도 메모리 DB와 5174 포트의 테스트 서버에서 실행하며, 개발용 DB에 기록을 추가하지 않습니다. Windows의 Microsoft Edge를 headless로 사용합니다. 다른 환경에서는 Playwright 설정의 `channel`을 환경에 맞게 바꾸세요. 화면 캡처는 개발 서버가 필요합니다. API 테스트는 별도 메모리/테스트 DB에서 계정·소유권·대화 비공개·위치 비공개·푸시 재시도·SSE·재시작 영속성을 검증합니다.

이메일 인증(24시간 일회용 링크), 비밀번호 복구(30분 일회용 링크), 기존 세션 해제, 계정 삭제를 구현했습니다. Resend 발신 설정이 필요하며 실제 외부 메일 도착은 아직 검증하지 않았습니다. 웹앱 manifest·설치 아이콘·안전 영역·키보드 대응·오프라인 안내와 기기 확인 화면을 추가했습니다.

**인터넷 배포와 실제 iOS/Android 나침반 정확도·푸시 도착 검증은 아직 완료되지 않았습니다.** 도메인·서버·메일 계정 정보가 필요합니다. [실기기 검증표](docs/DEVICE-QA.md)에 자동화와 실제 기기 검증을 구분했습니다. 공공 보호 정보 API와 서비스 운영 정책도 연결·확정 전입니다.

## 주요 파일

- `src/main.js`, `src/style.css`, `src/quality.css`: 반응형 화면과 사용자 흐름
- `src/wizard.js`: 단계별 폼·초안 복원
- `src/timeline.js`, `src/maps.js`, `src/domain.js`: 지도·시간순 탐색·검색·추천
- `src/client-store.js`: 서버 연동·실시간 갱신·푸시 구독
- `server/app.js`: SQLite API·인증·권한·알림 큐
- `public/assets/`: 실제 사용 이미지 및 최적화 WebP
- `docs/mascot-prompts.md`: 마스코트 생성·누끼 수정 기록
- `artifacts/`: 모바일/데스크톱 및 투명도 검토 자료

참고한 공식 문서: [Node SQLite](https://nodejs.org/download/release/latest-v24.x/docs/api/sqlite.html), [브라우저 Push 구독](https://developer.mozilla.org/en-US/docs/Web/API/PushManager/subscribe).
